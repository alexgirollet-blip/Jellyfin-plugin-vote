Save these settings as a template

A recurring template never opens a vote by itself: it prepares a draft and tells you (Votes tab and webhook). You review it, then press Create vote.

Entry points: turn them on one at a time

A fresh install starts with every optional entry point OFF and preview mode ON (only administrators see anything). The admin page and the standalone page always work. Turn on ONE entry point, save, reload Jellyfin in your browser, check it (and the Status tab), then the next one. Go live from the Status tab when you are happy.

Vote tab (Custom Tabs): manual, safe setup

Media Vote never changes Custom Tabs' settings. To add a Vote tab yourself:

  1. Make sure preview mode is OFF first (or your friends will see an empty tab while you test).
  2. Open Dashboard → Plugins → Custom Tabs and add a new tab. Title: Vote.
  3. Paste exactly the HTML below as its content. Do not add anything else: Custom Tabs 0.2.x pastes tab HTML into the home page's JavaScript, so a single apostrophe, backslash or dollar sign anywhere in a tab can blank the home screen.
  4. Save in Custom Tabs, then tick "I have added the Vote tab" above and save here.
  5. Reload Jellyfin in the browser (phones: fully close and reopen the app).

If the tab ever shows only "Media Vote is loading", the Media Vote script was not loaded (banner and tab both off, preview mode for that user, or the DISABLE file): the page itself is never affected.
